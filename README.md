# Marketing Campaign Performance Analytics

## Overview
A comprehensive marketing analytics project evaluating campaign performance across 25+ channels. Analyzing a dataset of 50,000+ impression and engagement metrics, this project isolates underperforming ad groups and provides actionable insights for budget reallocation through comparative cohort analysis. 

## Key Features & Business Impact
* **Automated Data Cleaning:** Programmed automated data cleaning pipelines in Python (Pandas) processing 10,000+ raw records, effectively reducing missing data errors by **25%**.
* **Performance Tracking:** Calculated and tracked core performance metrics including Click-Through Rate (CTR), Conversion Rate, and Return on Investment (ROI).
* **Cohort Analysis:** Performed comparative cohort analysis across marketing channels to propose practical, data-backed budget reallocations.

## Tech Stack
* **Data Processing Pipeline:** Python (Pandas)
* **Database & Querying:** SQL (PostgreSQL) - *Aggregations, Cohort Analysis*
* **Analysis & Visualization:** Tableau, Advanced Excel

## Repository Structure
* `scripts/`: Python (Pandas) data cleaning and preprocessing pipelines.
* `sql/`: SQL queries for calculating CTR, ROI, conversion rates, and performing cohort analysis.
* `dashboards/`: Tableau visualization concepts and links.
